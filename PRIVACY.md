# Privacy Policy

PoseReferenceForge Local is a fully offline application.

## Data Collection

**No data is collected.** The application:
- Does not send telemetry
- Does not upload images
- Does not upload pose data
- Does not require an account
- Does not make network calls during normal operation
- Does not use cookies
- Does not track usage

## Model Downloads

The only network activity is the initial download of ML model files from official repositories (Ultralytics, PyTorch). These are one-time downloads.

## Local Storage

User data (projects, poses, exports) is stored locally on the user's machine in:
- `%USERPROFILE%\.posereferenceforge\` (settings)
- `%USERPROFILE%\PoseReferenceForge\` (projects, exports, cache)

## Diagnostic Reports

Diagnostic reports are generated only on explicit user request and exclude source images unless the user opts in.
