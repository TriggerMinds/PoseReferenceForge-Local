# PoseReferenceForge Local

A local Windows application that converts pose photographs into clean, reusable 3D mannequin pose-reference images for external AI image-generation workflows.

## Requirements

- Windows 11 64-bit
- NVIDIA GPU with 8+ GB VRAM (recommended)
- Python 3.12.10
- Blender 5.1 (for high-quality rendering)

## Quick Start

1. Clone or download this repository
2. Run `scripts\setup_windows.ps1`
3. Run `scripts\download_models.ps1`
4. Launch the application
